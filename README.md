# 依依无限制剧情生图 · SillyTavern 扩展 (`yiyi-local-illust`)

专为 **大世界跑团 / 长篇剧情** 设计的 SillyTavern 自动插画扩展：

- **24 小时即开即画（Mac 常驻 / 内置公网直连 + HTTPS 自动兜底）**：已内置 Mac 公网服务地址（HTTP 酒馆优先走高速直连，HTTPS 酒馆或直连不通时自动切换 Cloudflare HTTPS 隧道，无需自己手动修改或搭建同源反代）；后台对接 `WAI-Illustrious v17` + `Hyper-SDXL 8-step`（10 步高还原参数 + 强效防坏手/坏手指负向保护）与无限制 `4B` 剧情提炼模型，并提供明确的连接/密码/网关/超时诊断提示。
- **全能记忆适配 + 无插件剧情自总结（3 档模式）**：
  - **智能全适配（推荐）**：同时读取 **小白X (`LittleWhiteBox`)**、第三方表格/数据库/向量记忆插件（`extensionPrompts`、`sheets` / `hash_sheets` / `tableData`、MVU `stat_data` 等深层变量）、酒馆世界书与摘要；当没有安装任何记忆插件时，会自动从前文对话楼层提取人物外貌、穿搭、场景转换与前图锚点保持一致。
  - **仅剧情总结（无插件模式）**：跳过记忆插件与世界书，纯靠近 35 层剧情正文+状态栏视觉字段提取人物与场景特征。
  - **关闭历史记忆**：仅看当前楼层正文画面。
- **同层卡 / 伪同层全适配（悬浮画框 + 本局画廊 + 顶层穿透）**：遇到覆盖原楼层 DOM 或全屏弹窗的同层/伪同层角色卡（如隐藏 `#chat > .mes` 并覆盖全屏 `<iframe>` 的卡面）时，不再被卡面遮挡——扩展会自动检测到遮挡并弹出**可拖拽悬浮画框**、顶部全局进度条与全屏大图放大镜，并在悬浮球上提供直达 **🖌️ 立即画一楼** 与 **🖼️ 打开画廊（含插画数量角标）** 快捷按钮；原图仍同时写入 SillyTavern `mes.extra.media` 永久保存。
- **纯净楼层提取与永久保存**：自动剥离同层卡内嵌 `<head>`/`<svg>`/`<mvu>`/代码块、状态栏与选项文本，支持手动点击楼层 `🎨` 按钮或开启楼层自动生成（同层卡未触发楼层重绘事件时亦会自动兜底出图）。

## 安装方式（SillyTavern Git URL）

在 SillyTavern 的 **扩展（Extensions） → 安装扩展（Install extension）** 中填入仓库地址即可：

```text
https://github.com/luoyuewuyi/yiyi-local-illust
```

安装完成后点开悬浮窗，**无需修改默认服务地址**，只需在下方填入私密访问密码并点击 **测试连接** 即可开始使用（如从旧版本升级，之前保存的 `/yiyi-mac` 也会自动切换为内置公网地址）。
