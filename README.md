# 依依云端无限制剧情生图 · SillyTavern 扩展 (`yiyi-local-illust`)

专为 **大世界跑团 / 长篇剧情** 设计的 SillyTavern 无限制插画扩展（v2.1.0）：

- **MOSS-Image 顶配无审查多引擎自由切换（动态同步后端）**：
  - 默认启用 **`MOSS 二次元无审查旗舰 (moss_anime)`**，并内置 **`MOSS 酒馆极速无审查 (moss_turbo，18–26s)`**、**`MOSS 剧情双人/精准汉字旗舰 (moss_drama)`** 与 **`Qwen-Image-2.1 Noct-Q V4 (qwen_omni)`** 四档引擎离线兜底；连上云端网关后自动根据 `/api/st/ping` 动态刷新可用引擎与参数说明。
  - 支持 **`✨ 1.5× 超分精修 (hires_refine)`**（ScaleROPE 二阶段印刷级细节提升）与 **`🔥 成人细节增强 (nsfw_boost)`** 两个一键可选开关，并随单图元数据持久化保存。
- **不满意插画一键删除 & 原地安全重新生成（楼层卡片 / 悬浮画框 / 全屏灯箱三端统一）**：
  - **防误触永久删除**：点击 `🗑️ 删除` 就地变为暖红 `确认删除？`（3 秒自动复原，无弹窗打断），确认后同步清除 `mes.extra.media`、`swipe_info`、兼容旧单图与内联图片标记并立即 `saveChat()`，确保刷新网页或切角色/切 Swipe 后**绝不复活**；全删光后仍保留清晰的重画入口。
  - **原地安全重新生成**：点击 `🔄 重画` 自动分配全新随机种子并采用当前所选引擎（支持把旧图一键切换至 MOSS-Image 重画）；重画期间卡片展示毛玻璃实时进度遮罩与 `✕ 取消` 按钮，仅在新图成功上传保存后才原子替换旧图，失败/取消完好保留原图；旧版本无元数据历史图自动降级从楼层正文重新提取提示词。
  - **桌面与手机双端零遮挡**：桌面端悬浮毛玻璃胶囊操作条并避让酒馆原生翻页控件；移动端/触屏自动变为图片下方一体停靠底栏，0 遮挡画面主体、单手顺手可点。
- **全能记忆适配 + 同层卡全适配**：
  - 自动读取 **小白X (`LittleWhiteBox`)**、第三方表格/变量记忆插件、世界书与前文剧情特征保持人物一致；遇到全屏同层/伪同层角色卡时自动启用可拖拽悬浮画框与全屏灯箱。

## 安装与更新（SillyTavern Git URL）

在 SillyTavern 的 **扩展（Extensions） → 安装扩展（Install extension）** 中填入仓库地址即可：

```text
https://github.com/luoyuewuyi/yiyi-local-illust
```

已安装旧版的用户直接打开右下角悬浮窗点击 **🔄 更新** 即可一键拉取最新版并自动刷新生效。
